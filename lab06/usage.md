# Как пользоваться

## Установка Python

- **macOS**: обычно Python 3 уже есть. Если нет — `brew install python` или скачать с python.org.
- **Linux**: обычно Python 3 уже установлен. Проверьте `python3 --version`. Если нет pip — `sudo apt install python3-pip` (Ubuntu/Debian) или `sudo dnf install python3-pip` (Fedora).
- **Windows**: скачайте установщик с python.org, при установке поставьте галочку "Add Python to PATH". Или установите `python` из Microsoft Store.

## Установка psutil

**Windows:**

```
python -m pip install psutil
```

**macOS / Linux:**

Если `pip` выдаёт ошибку `externally-managed-environment`, используйте один из вариантов:

1. Быстрый способ для лабораторной работы:

```
python3 -m pip install psutil --break-system-packages
```

2. Через виртуальное окружение (рекомендуется):

```
python3 -m venv venv
source venv/bin/activate
python3 -m pip install psutil
```

После активации окружения программа запускается как обычно: `python3 main.py --mode broadcast`.

## Запуск на macOS / Linux

Broadcast:

```
python3 main.py --mode broadcast
```

Multicast:

```
python3 main.py --mode multicast
```

## Запуск на Windows

В PowerShell или CMD:

Broadcast:

```
python main.py --mode broadcast
```

Multicast:

```
python main.py --mode multicast
```

Если команда `python` не найдена, попробуйте:

```
py -3 main.py --mode broadcast
```

## Первый запуск

При старте программа автоматически определяет активный интерфейс и печатает:

```
interface <имя>
ip <ip>
mask <маска>
broadcast <broadcast>
mode <broadcast|multicast>
commands: /list, /ignore <ip>, /unignore <ip>, /leave, /help, /quit
```

## Сценарий "точка доступа с телефона"

1. Включите на телефоне раздачу Wi-Fi (Personal Hotspot / Точка доступа).
2. Подключите все ноутбуки — включая свой — к этой Wi-Fi-сети.
3. На каждом ноутбуке установите `psutil` и запустите программу.
4. Для сети с телефона рекомендуется broadcast-режим — multicast часто блокируется мобильными точками доступа:

```
python3 main.py --mode broadcast
```

На Windows:

```
python main.py --mode broadcast
```

5. После старта программа напечатает свой `ip` и `broadcast`.
6. Подождите 3–5 секунд, пока придут маяки. При обнаружении каждого участника появится `peer <ip>`.
7. Проверьте список активных приложений:

```
/list
```

8. Введите текст и нажмите Enter — сообщение увидят все, кто в сети.

## Брандмауэр

- **macOS**: если сообщения не доходят, разрешите Python/Terminal в "Системных настройках → Сеть → Брандмауэр".
- **Linux**: откройте UDP-порты:

```
sudo ufw allow 10000/udp
sudo ufw allow 10001/udp
```

- **Windows**: при первом запуске Windows Defender может спросить разрешение — выберите "Частные сети". Если нет — добавьте разрешающие правила для входящих UDP-портов 10000 и 10001.

## Как отправить сообщение

Введите текст и нажмите Enter — сообщение сразу уходит всем участникам в текущем режиме. Входящие сообщения появляются сразу, как только доходят. Промпт не выводится, вводите текст прямо в терминал.

## Команды

### `/list`

Выводит актуальный список IP-адресов запущенных приложений. Пиры, от которых не приходило маяков 9 секунд, пропадают из списка.

### `/ignore <ip>`

Локально игнорирует указанный IP, рассылает команду `IGNORE|<ip>` всем участникам и выводит подтверждение. Все, кто получит команду, тоже перестанут показывать сообщения от этого хоста и увидят уведомление. Пример:

```
/ignore 192.168.1.5
```

### `/unignore <ip>`

Отменяет игнорирование указанного IP. Рассылает команду `UNIGNORE|<ip>` всем участникам, кроме самого заигнорированного ПК — его собственный `/unignore` не обрабатывается. Пример:

```
/unignore 192.168.1.5
```

### `/leave`

Рассылает уведомление `LEAVE|<ip>` всем участникам, удаляет отправителя из их списков пиров и останавливает отправку маяков. В multicast-режиме дополнительно вызывает `IP_DROP_MEMBERSHIP` — приложение перестаёт получать multicast-группу.

### `/help`

Выводит список команд.

### `/quit`

Корректно завершает программу.

## Особенности по ОС

### macOS

- Python из Homebrew может требовать `--break-system-packages` или venv.
- Встроенный фаервол может блокировать входящий UDP. Разрешите Terminal/Python в "Системных настройках → Сеть → Брандмауэр".
- multicast на точках доступа с iPhone/Android часто отключается — используйте broadcast.

### Linux

- Может потребоваться открыть порты в `ufw` или `firewalld`.
- Права root не нужны, но фаервол по умолчанию может режет UDP.

### Windows

- Используйте `python` или `py -3` в зависимости от установки.
- Windows Defender обычно спрашивает разрешение при первом запуске — выберите "Частные сети".
- Если программа не видит пиров, проверьте, что Wi-Fi сеть отмечена как "Частная", а не "Общедоступная".
- multicast может не проходить на некоторых Wi-Fi адаптерах/драйверах; broadcast надёжнее.

### Точка доступа с телефона

- Все устройства должны быть подключены к одной точке доступа.
- Многие телефоны блокируют multicast и/или включают "изоляцию клиентов". broadcast-режим работает чаще.
- iOS Personal Hotspot выдаёт небольшой пул адресов; если устройств больше, чем позволяет iOS, используйте Android или отдельный роутер.

## Проверка

Запустите программу на двух и более машинах, подключённых к одной локальной сети. На всех машинах выберите одинаковый режим. Убедитесь, что брандмауэр не блокирует UDP-порт 10000 (broadcast) или 10001 (multicast). Режим multicast будет работать, только если коммутатор/роутер пропускает multicast-трафик внутри локальной сети.
